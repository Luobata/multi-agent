# Phase 02 · 档案室视觉回归

## 基线

- 应用底：暖灰纸；详情：浅米白纸；正文：近黑墨色。
- 中文标题用宋体类字体；机器信息用系统等宽字体。
- 朱红用于档案编号和选中索引，绿色仅用于状态，蓝色用于焦点和信息。

## 组件

- 导航改为浅色索引抽屉，品牌章为“档 / 档案室”。
- 记录选中态使用纸面、细线与左侧 3px 朱红索引。
- dossier 使用双线外框和单层纸张硬影。
- 主按钮黑底白字，次按钮纸底黑字，归档按钮朱红描边。
- 弹窗、抽屉、Toast 与拓扑图统一回纸张表面。

## 移除

- 暗色基底、磷光绿主色、霓虹、扫描线、棋盘纹、像素切角、硬黑像素阴影和装饰 HUD。

## 响应式

- 宽桌面保持三栏。
- 900px 以下列表堆叠到 dossier 上方，匹配参考图形态。
- 640px 以下使用底部导航，正文区块和表单改为单列。
